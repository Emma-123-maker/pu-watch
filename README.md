# PU-Watch - Polling Unit Watch

> Every Polling Unit becomes a live broadcaster for transparent elections.

### The Problem
What happens at the Polling Unit is what gets changed at collation. No verifiable record.

### The Solution
PU-Watch lets observers check-in at any of the 176,846 PUs, with GPS + timestamp proof, and upload:
1. BVAS accreditation photo
2. Number of accredited voters
3. 30-sec voting clips
4. Counting video
5. EC8A result sheet (most important)

### Features
- Offline-first PU search (all 176k PUs bundled)
- GPS + Time stamped reports
- EC8A overlay camera
- Live public feed by State/LGA/PU
- Collation verification dashboard

Built with Flutter + Firebase.
